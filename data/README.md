# Data

## sample_data.csv

Simulated plot-level dataset that mirrors the structure of the original field study. This file is provided to demonstrate the analytical workflow. It is not real field data.

**Study design reflected in the data:**
- 10 control plots within Kasewe Hills Forest Reserve (KHFR)
- 30 fallow plots in communities surrounding KHFR (Moyamba District)
- 30 fallow plots in communities surrounding BHFR (Bo District)
- 70 plots total
- No control plots at Bojene (this is a known limitation of the original study)

**Columns:**

| Column | Description | Unit |
|--------|-------------|------|
| plot_id | Unique plot identifier | - |
| study_site | KHFR, KHFR_surroundings, or BHFR_surroundings | - |
| plot_location | Reserve interior (control) or Community fallow land (fallow) | - |
| age_class | Fallow age class: farmbush, young_secondary, old_secondary, control | - |
| fallow_years | Approximate years since last cultivation | years |
| stems_ha | Stem density | stems per hectare |
| basal_area_m2_ha | Basal area | m2 per hectare |
| agb_mg_ha | Aboveground biomass | Mg per hectare |
| agc_mg_ha | Aboveground carbon | Mg C per hectare |

**Fallow age ranges (from community-confirmed ages):**
- Farmbush: 0 to 4 years
- Young secondary: 5 to 9 years
- Old secondary: 10 to 16 years
- Control: approximately 60 years standing
